Foundational Thinking Sessions

← Home

This program contains structured sessions. Each session builds on the previous one to develop foundational thinking habits.

  • Session 1 - Noticing Sameness
    See what is similar between objects.
  • Session 2 - Noticing Difference
    Find what does not belong.
  • Session 3 - Grouping by One Rule
    Sort objects using a single visible property.
  • Session 4 - Switching the Rule
    Change how objects are grouped.
  • Session 5 - Completing Patterns
    Recognize and extend simple patterns.
  • Session 6 - Comparing
    Understand bigger, smaller, more, less.
  • Session 7 - Matching & Pairing
    Identify logical pairs.
  • Session 8 - Spatial Thinking
    Understand position and orientation.
  • Session 9 - Logical Elimination
    Rule out what cannot fit.
  • Session 10 - Explaining Reasoning
    Answer "why?" clearly and confidently.
