Session 3 – Grouping by One Rule

In this session, children practice grouping objects based on one shared rule. Only one rule should be used at a time.

Session Goal: Help your child group objects using one visible property.

Activity 1

●
●
■
■
For parents:

Ask: Can you group these by color?

If unsure, say: Which ones are the same color?

Rule to notice: Color

Activity 2

●
■
●
■
For parents:

Ask: Can you group these by shape?

If unsure, say: Which ones have the same shape?

Rule to notice: Shape

Activity 3

●
●
■
■
For parents:

Ask: Can you group these by size?

If unsure, say: Which ones are bigger? Which ones are smaller?

Rule to notice: Size

You have completed Session 3. Grouping by a single rule strengthens classification skills.
