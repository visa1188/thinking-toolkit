Session 6 – Comparing

In this session, children practice comparing objects based on size and quantity. They learn to observe differences and describe them clearly.

Session Goal: Help your child compare objects using words like bigger, smaller, more, and less.

Activity 1

●
●
For parents:

Ask: Which one is bigger? Which one is smaller?

What to notice: Size comparison

Activity 2

● ● ●
● ●
For parents:

Ask: Which group has more? Which has less?

What to notice: Quantity comparison

Activity 3

For parents:

Ask: Which line is longer? Which is shorter?

What to notice: Length comparison

You have completed Session 6. Comparing builds foundational reasoning skills for mathematics and everyday decisions.
